# Monopoly 3D (Hotseat)

Juego tipo Monopoly en 3D para jugar con amigos en el mismo ordenador.

## Cómo jugar

1. Abre `index.html` en un navegador moderno con internet.
2. Elige el número de jugadores.
3. Pulsa **Iniciar partida**.
4. Cada turno:
   - Lanza dados.
   - Compra la propiedad si está libre.
   - Termina turno.

## Reglas incluidas

- Dinero inicial: $1500.
- Al pasar por salida: +$200.
- Compra de propiedades y cobro de rentas.
- Casillas de impuestos y eventos aleatorios.
- Ir a la cárcel.
- Bancarrota y condición de victoria.

> Nota: Es una versión rápida/familiar, no una réplica legal exacta del Monopoly original.
